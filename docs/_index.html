Overview

Overview, your browser research finally has structure.

We built TabNeuron for people who hit the limits of traditional tab bars. Research sprawls across dozens of pages, key context disappears the moment a browser session closes, and most AI tools still behave like stateless chat windows that know nothing about your ongoing work.

TabNeuron is a personal AI browser workspace. It maps your active tabs onto a visual canvas, lets you organize them spatially, chats with websites and the live internet, automates repetitive research work, and keeps a memory of your projects and preferences so every session starts with context instead of friction.

Why TabNeuron

Because web research should feel like a workspace, not a pile of tabs.

The problem: important pages vanish into flat browser strips and every deep research session becomes a game of tab archaeology.

How TabNeuron fixes it: your tabs live on a 2D canvas where AI groups them by meaning, not just open order. You can drag, rename, cluster, and revisit a research layout long after the browser window changes.

The problem: most assistants forget your priorities, past findings, and browsing patterns between sessions.

How TabNeuron fixes it: AI memory extracts observations, preferences, and project context over time, then uses profile-first retrieval and conversation compaction to stay fast even across long-running work.

The problem: reading, comparing, extracting, and saving information from multiple tabs still means endless copying and switching.

How TabNeuron fixes it: chat with selected tabs, scrape and compare content, chain agents together, and push final outputs back into your workspace as persistent artifacts.

Core features

Same strong AI foundations as Sorana, adapted for the browser.

Visual tab canvas

Break tabs out of the browser chrome and arrange them on an infinite desktop canvas. AI groups by topic, while the canvas editor gives you manual control over layout, naming, and structure.

  • AI-organized 2D workspace for browser tabs.
  • Drag-and-drop editing, resizing, regrouping, and mind map generation.
  • Saved workspace states so research remains visible beyond a single session.

Chat with websites

Select one or many tabs and ask questions in plain language. DOM content and metadata are fed into your model context so the AI can compare sources, extract facts, and synthesize findings directly from the pages you are viewing.

  • Multi-tab comparison and summarization.
  • Metadata, page content, and live web context in one workflow.
  • Useful for specs, tutorials, product research, and article synthesis.

AI memory that learns your workflow

Like Sorana, TabNeuron keeps a growing knowledge profile based on your conversations. It captures preferences, facts, project context, and entities, then retrieves the right amount of memory so the assistant stays accurate without flooding the context window.

  • Automatic observations and profile building.
  • Conversation compaction for large token savings over time.
  • Cross-agent and import/export memory workflows.

MCP automation and research pipelines

TabNeuron is not just for reading tabs. It can search the web, fetch content, write files, connect to third-party MCP servers, and chain no-code agents into repeatable research flows where one agent hands structured output to the next.

  • Visual MCP manager with configurable server connections.
  • Built-in file and web tools through conversation.
  • No-code agent pipelines for repeatable research tasks.

AI memory

A browser workspace that remembers how you work.

TabNeuron uses the same memory principles that make Sorana compelling: active conversation context, auto-compaction, observation extraction, profile-first retrieval, and fallback detail search when needed. The result is an assistant that gets more useful over time instead of getting slower, more expensive, or more forgetful.

Profile-first retrieval

Compact summaries load first for speed, with detailed memories as backup.

Adaptive search

Semantic search, keywords, and full-text fallback keep answers precise.

Long-session friendly

Old chats compress into smaller summaries while preserving useful context.

Shared knowledge

Memories can be reused across agents and projects instead of staying siloed.

What this changes in practice

  • Your research sessions pick up where you left off.
  • Only relevant context is loaded, so local inference stays efficient.
  • Answers reflect your domain, habits, and ongoing projects.
  • Large browsing sessions remain manageable over weeks and months.

Automation

MCP servers, website chat, OCR, vision, and agent pipelines.

MCP server integrations

Connect file tools, web tools, and external services such as GitHub, Google Drive, databases, or custom MCP endpoints through a visual manager instead of hand-editing config files.

OCR and vision

Process scanned PDFs, screenshots, and images so visual material becomes searchable and usable in AI workflows. Vision-capable models can interpret UI, charts, notes, and diagrams directly.

Agent pipelines

Build chained workflows where one agent scrapes or extracts, another compares and structures, and a final agent writes a report back into the workspace.

AI & models

Use local models for privacy, add cloud models when you need raw power.

TabNeuron supports local and on-prem backends including Lemonade with FastFlowLM, Ollama, Llama.cpp, and other self-hosted LLM stacks, plus cloud providers when you want broader model choice. Like Sorana, it benefits from stronger chat models and, when available, separate embedding models for retrieval-heavy workflows.

Lemonade is the most capable setup for split-view model management, letting you run a chat model and embedding model at the same time for better routing, retrieval, and local acceleration.
