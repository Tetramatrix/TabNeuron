Privacy Policy.

Tetramatrix Connector. Complete transparency on data handling and local processing.

Last updated: March 2026

This policy applies to the Tetramatrix Connector Chrome extension and the TabNeuron desktop application. It is written to be as simple and transparent as possible.

Data collection.

Nothing leaves your machine, ever.

Tetramatrix Connector does not collect, store, or transmit any personal user data to external servers or third parties.

There are no accounts, no cloud sync, no telemetry, and no analytics. The app and extension run entirely on your device.

Local data processing.

Your browsing session stays on your device.

The extension reads tab URLs, titles, and page content exclusively to forward them to the Tetramatrix desktop application (TabNeuron) running locally on the user's own machine via localhost:5555. This data never leaves the user's device.

Workspace states, chat history, AI memory, and settings are stored in a local .tabneuron/ folder on your machine. Cloud AI providers are only contacted if you explicitly connect your own API key.

Permissions.

Used solely to enable local communication between Chrome and TabNeuron.

Permissions (tabs, tabGroups, scripting, storage, activeTab) are used solely to enable communication between Chrome and local Tetramatrix applications. No data is logged or stored remotely.

See the Chrome extension page for a full explanation of each permission and its purpose.
