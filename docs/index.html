Why TabNeuron? Because research deserves space.

Common browser frustrations and how TabNeuron solves them.

Your tabs are buried in browser bars

Scrolling through dozens of hidden tabs, losing context. "Which tab has that info?" AI groups tabs on a 2D canvas by topic, so you find tabs by what they're about, not where they're buried.

AI forgets everything between sessions

TabNeuron automatically extracts facts, skills, preferences, and personas from your conversations. Long term profiles make answers more accurate over time.

Web research is manual

Opening and reading across multiple tabs takes too long. Select multiple tabs and ask the AI to synthesize, compare, or extract data across all of them simultaneously.

Workspace and browser are disconnected

Bidirectional sync with Chrome Tab Groups: canvas changes push to the browser, browser changes pull to the canvas. Your browser and workspace stay aligned.

You can't tell what a tab contains

Titles alone aren't enough. Automatic scaled screenshots, titles, URLs, and OG-tags are extracted for every tab for instant visual context without switching.

Repetitive file and web tasks are manual

Built-in MCP server and integrations handle file operations (read, write, move, search, edit) and web tools like fetch, scrape, search, and extract, all through conversation.

Your data goes to the cloud with no privacy

Run models locally with Lemonade (NPU acceleration), Ollama, Llama.cpp, or LM Studio, so nothing leaves your machine. Connect cloud AI only when you need the power.

Long chats get slow and expensive

Auto-compaction summarizes old conversations with up to 93% token savings and full context preserved. Projects that span months stay fast and affordable.

Core features for serious research.

Everything you need in a single workspace: spatial organization, AI chat, agents, memory, and browser sync.

Organize Tabs on Canvas

AI groups your open tabs on a 2D canvas by topic, so you visually find tabs by what they're about, not where they're buried. The canvas editor gives you full visual control: drag and drop, rename, and resize. Generate mind maps from your tab groups to reveal hidden relationships between topics.

Visual Previews & Metadata

Automatic scaled screenshots, titles, URLs, and OG-tags extracted for every tab for instant visual context. Workspace states are saved locally to disk, so closing the browser never loses your research session.

Canvas ↔ Browser Sync

Bidirectional sync with Chrome Tab Groups. AI suggests semantic groupings; review and click "Apply" and browser tab groups update instantly. Create groups in the browser and TabNeuron's polling API detects the change and pulls it onto the canvas.

Chat with Websites

Select multiple tabs and ask the AI to synthesize, compare, or extract data across all of them simultaneously. DOM extraction feeds page content and metadata directly into the LLM context with no manual reading. "Compare specs across 4 review tabs" → result saved locally.

AI Agent Pipelines

Build no-code automated workflows where one agent's output becomes the next agent's input. A Scraper Agent reads selected tabs and extracts links and specs, an Analyst Agent compares and formats a Markdown table, and an Output Agent writes an executive summary saved as a persistent text node on the canvas.

AI Memory That Remembers

Automatically extracts facts, skills, preferences, and personas from conversations, so it gets better over time. Auto-compaction summarizes old conversations with up to 93% token savings while preserving full context, and a global memory is shared across all agents with import/export.

MCP Server & Integrations

Visual MCP Manager to enable, disable, and monitor servers. File operations (read, write, move, search, edit) all through conversation. Web tools for fetch, scrape, search, and extract, plus external servers for Google Drive, GitHub, PostgreSQL, and custom tools.

AI Backends: Local or Cloud

Local: Lemonade (NPU acceleration), Ollama, Llama.cpp, and LM Studio, so nothing leaves your machine. Cloud: OpenAI, Mistral, Gemini, and more when you need power. The Model Manager activates or deactivates models per task with a 2-pane view for chat and embeddings simultaneously.

Portable & Private

Runs from a USB stick. Extract anywhere, no installation, no admin rights. All data lives in a single .tabneuron/ folder, and the lightweight browser bridge connects via a local polling API, so no data leaves your machine.

Common questions.

Quick answers before you download.

Does TabNeuron cost anything?

No. TabNeuron is completely free for everyone. Download the portable executable, install the free Chrome extension, and run AI models locally or connect cloud providers with your own key.

Does my data leave my machine?

By default, everything stays local. TabNeuron stores its workspace data in a local .tabneuron/ folder, and the browser extension connects through a local polling API on localhost:5555. Cloud AI providers are only used when you explicitly connect an API key.

Can I run it from a USB stick?

Yes. TabNeuron is a portable executable. Extract it anywhere and run it; no installation, no registry changes, no admin rights required.

Which browsers are supported?

Google Chrome is required for the Tetramatrix Connector extension. TabNeuron syncs bidirectionally with Chrome Tab Groups through a local polling API on port 5555.

What happens to long conversations?

Auto-compaction summarizes old conversations, saving up to 93% of tokens while preserving full context. AI memory also extracts facts, skills, preferences, and personas from your chats, building long term profiles that make answers more accurate over time.
